LOOP LOCAL — VIDEO LIBRARY

PUBLIC WEBSITE
https://kiran6767aj-ops.github.io/

FILES
- index.html: page content and structure, including the AdSense site code
- styles.css: dark video-library design and responsive layout
- script.js: local file selection, multi-video library, search, filters, and playback
- ads-config.js: AdSense publisher ID and the two responsive ad-unit IDs
- ads.js: loads the configured display ads into the page placements

OPEN AND USE
Open the public link above, or double-click index.html to preview the editable local copy. Choose “Upload videos” or “Add videos” and select one or more video files. Search by file name, use the filters, play previews, or remove videos from this session.

ADS
The AdSense code, publisher ID, two display ad units, and Auto ads are configured. Google verified site ownership and the site review request is pending. Google must approve the site before ads can serve; the page may continue to show ad placeholders until approval. Review timing and approval are controlled by Google.

STORAGE NOTE
Videos are selected from your device and previewed locally in the browser. They are not uploaded to a server, stored online, or available to other people. The local list clears when the page is closed or refreshed. Public uploads and permanent storage require a server and storage service.
